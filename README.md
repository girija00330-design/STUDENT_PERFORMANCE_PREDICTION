
## 📌 Project Description

This project predicts whether a student will Pass or Fail
based on Study Hours, Attendance, and Previous Marks.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

## 🤖 Machine Learning Algorithm

Decision Tree Classifier

## 📊 Input Features

- Study Hours
- Attendance
- Previous Marks

## 🎯 Output

- Pass
- Fail

## 🚀 How It Works

1. Collect student data
2. Prepare the dataset
3. Train the Machine Learning model
4. Test the model
5. Enter new student details
6. Predict Pass or Fail
